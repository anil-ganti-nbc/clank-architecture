# ARCHITECTURE_PRINCIPLES

The normative principles are maintained in
[CANONICAL_CLANK_ARCHITECTURE_v0.1.md](CANONICAL_CLANK_ARCHITECTURE_v0.1.md).
This file is a stable pointer so historical references remain valid; it is not
an alternate or lower-fidelity source of canon.

Primary canon takes precedence. The review-derived rules in
[ADR-0004](adr/0004-secondary-review-rule-integration.md) are mandatory only
when congruent and must be reconciled by ADR when they conflict.

The archaeology-derived integration amendment is
[CANONICAL_CLANK_ARCHITECTURE_v0.2.md](CANONICAL_CLANK_ARCHITECTURE_v0.2.md),
adopted by [ADR-0005](adr/0005-archaeology-ratified-integration-gates.md).
Observer-only operation, instance/lane identity, baseline handover, and
corroborated scheduler authority are now explicit principles.
